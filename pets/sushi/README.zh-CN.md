# SuShi

[English](README.md)

SuShi 是一只以苏轼为灵感的温暖像素风桌面宠物。它兼容 Codex sprite v2，
包含九组标准动画与十六个顺时针观察方向。

![SuShi 预览](preview.webp)

把 `pet.json` 和 `spritesheet.webp` 一起放入 Codex 宠物渲染器支持的目录即可安装。
图集尺寸为 1536x2288，单元格为 192x208。安装和使用不需要生产项目、模型凭据或
Python 环境。
